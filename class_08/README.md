### 1. Armstrong Number
* **File**: [`ArmStrong.java`](file:///c:/Users/Vivek%20kumar%20Gupta/Desktop/JSpider/programming/class_08/ArmStrong.java)
* **Question**: Write a Java program to check whether a given number is an Armstrong number.
* **Concept**: An Armstrong number (or Narcissistic number) of order $n$ is equal to the sum of its own digits each raised to the power of $n$ (where $n$ is the total count of digits).
* **Example**: 
  - $153 \rightarrow 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153$
  - $9474 \rightarrow 9^4 + 4^4 + 7^4 + 4^4 = 9474$

### 2. Automorphic Number
* **File**: [`autoMophic.java`](file:///c:/Users/Vivek%20kumar%20Gupta/Desktop/JSpider/programming/class_08/autoMophic.java)
* **Question**: Write a Java program to check whether a given number is an Automorphic number.
* **Concept**: An Automorphic number is a number whose square ends in the same digits as the number itself.
* **Example**:
  - $5 \rightarrow 5^2 = 25$ (ends in 5)
  - $6 \rightarrow 6^2 = 36$ (ends in 6)
  - $25 \rightarrow 25^2 = 625$ (ends in 25)
  - $76 \rightarrow 76^2 = 5776$ (ends in 76)

### 3. Print / Count Palindrome Numbers in Range
* **File**: [`count_Palinndrome.java`](file:///c:/Users/Vivek%20kumar%20Gupta/Desktop/JSpider/programming/class_08/count_Palinndrome.java)
* **Question**: Write a Java program to print all Palindrome numbers in the range from 1 to N.
* **Concept**: A Palindrome number remains the same when its digits are reversed.
* **Example**:
  - $121 \rightarrow$ Reverse is $121$
  - Range $N = 500$: Prints all single-digit numbers and palindromes up to 500 ($1, 2, \dots, 9, 11, 22, \dots, 494$).
